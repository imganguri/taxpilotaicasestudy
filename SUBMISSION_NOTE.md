# Submission Note

I built **TaxPilot AI**, a working frontend prototype covering all ten product challenges in the case study. The prototype is intentionally powered by hardcoded tax records, generated document data, and simulated AI responses so the work stays focused on the evaluated frontend concerns: visual design, interaction design, information architecture, role-aware experiences, traceability, prioritization, and trust.

The working interactions include role switching, priority filtering, document search and pagination, contextual navigation, source-region traceability, AI verification and correction with an audit trail, contextual client/internal messaging, task ownership, issue resolution, client onboarding progress, and audience-specific status views.

OCR, tax calculations, file storage, authentication, AI inference, and backend messaging are simulated. In a production implementation, the same frontend contracts would connect to document-processing, tax-engine, identity, workflow, and messaging services.
